# 💄 流行りのメイクを深掘り！コメント分析ツール

YouTubeのコメントを収集・分析し、特定のメイクや美容トレンドに対するユーザーの生の感想・評価を可視化するソーシャルリスニングツール。

## 概要

ユーザーが入力したキーワードに関連するYouTube動画を検索し、コメントを自動収集。日本語BERTモデルによる感情分析、クラスタリング、LLMによる洞察生成を通じて、コメントの背後にあるニーズや不満を可視化する。

## 主要機能

- **キーワード検索・コメント自動取得**：YouTube動画をキーワード検索し、選択した動画のコメントを取得
- **感情分析**：日本語BERTモデルでコメントをポジティブ/ネガティブ/ニュートラルに分類
- **多角的な可視化**：感情割合グラフ、確信度フィルター、頻出単語ランキング、ワードクラウド
- **コメントの自動クラスタリング**：Sentence Transformers + KMeansで話題ごとにグループ化
- **LLMによる詳細分析**：Gemini APIでネガティブコメントから改善提案、ポジティブコメントから強みを生成
- **代表コメントの抽出・CSVダウンロード**

## 実装上の工夫と課題への対応

1. **コメント取得とモデル選定**
   YouTubeのコメント取得ライブラリが頻繁に仕様変更し動作不良を起こしたため、安定して取得できるyt-dlpに切り替え。感情分析モデルも複数試す中で環境依存のエラー（OSError等）に直面し、最終的にローカルで安定動作する日本語BERTモデル（`koheiduck/bert-japanese-finetuned-sentiment`）を採用。

2. **日本語表現とノイズへの対応**
   絵文字・顔文字・ネットスラング（「wwww」「草」等）を意味の近い日本語表現に変換する前処理を実装。加えて、配信者への賞賛コメント（「可愛い」「最高」等）が多いと、動画の主題に対する評価や不満が埋もれる問題に着目し、Janomeで抽出した名詞のうち賞賛語の割合が50%を超えるコメントを分析対象から除外する独自ルールを実装。

3. **データ量と分析の深さを考慮した2段階設計**
   当初は複数動画のコメントをまとめて分析する構成も検討したが、動画ごとの文脈や特徴的な意見が平均化され、結果が一般的で面白みに欠けると判断。検索結果から1本を選んで深掘りする設計に変更した。加えて、最新動画はコメント数が少ない場合があるため、情報鮮度と分析に必要なデータ量のトレードオフも考慮している。

4. **確信度フィルタリング**
   感情分析の確信度スコアをスライダーで指定し、曖昧な判定を除外しながら閾値ごとの結果を比較できるようにした。

5. **E5＋KMeansによる話題分類**
   `intfloat/multilingual-e5-large`でコメントをベクトル化しKMeansでクラスタリング。分類数はスライダーで2〜6の範囲で指定可能（コメント数が20件未満の場合は実行しない制限あり）。確信度フィルターとは独立した機能で、感情の確信度ではなく話題の近さでコメントをグループ化する。

6. **Geminiのプロンプト設計**
   「美容トレンドを分析する専門家」という役割と、感情ラベルごとの出力項目（不満点・改善提案／評価点・強み）をプロンプトで指定し、構造化された洞察を生成する設計。

## 使用技術

- **フロントエンド/UI**: Streamlit
- **感情分析**: Transformers（`koheiduck/bert-japanese-finetuned-sentiment`）
- **クラスタリング**: Sentence Transformers（`intfloat/multilingual-e5-large`）, scikit-learn（KMeans）
- **LLM連携**: Google Gemini API（`gemini-3.8-flash`）
- **データ収集**: yt-dlp, youtube-search-python
- **前処理/可視化**: Janome, pandas, matplotlib, WordCloud

## ローカルでの起動方法

```bash
# 1. 仮想環境の作成・有効化
python -m venv venv
source venv/bin/activate  # macOS/Linux

# 2. 依存パッケージのインストール
pip install -r requirements.txt

# 3. .env ファイルを作成し、Gemini APIキーを設定
echo "GEMINI_API_KEY=<発行したAPIキー>" > .env
# ※ 感情分析・クラスタリングのモデルは公開モデルのため、Hugging Faceトークンは不要です

# 4. アプリの起動
streamlit run app.py
```
